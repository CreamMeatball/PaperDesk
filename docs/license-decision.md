# Project license decision

Status: Apache-2.0, explicitly selected by the owner on 2026-10-29 (Asia/Seoul), superseding the earlier MIT choice for the current source and future project releases. Previously built artifacts are retained with their original license files.

The root LICENSE contains the unmodified Apache License 2.0 text. NOTICE records the project attribution, Copyright 2026 Paperdesk contributors. Both files are included in package metadata, wheels and macOS app resources.

Third-party components retain their own licenses and notices. The remaining privacy/license release review also checks those bundled components; selecting Apache-2.0 does not mark that manual review or other release gates complete.
